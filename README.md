# Vižon - Premium Web Development

Modern web development agency website built with Next.js 15, featuring dynamic animations, admin panel, and content management system.

## 🚀 Features

- **Modern UI/UX**: Dynamic animations, scroll effects, and generative backgrounds
- **Admin Panel**: Full content management system for projects, services, contacts, and site content
- **Responsive Design**: Optimized for all devices
- **Performance**: Built with Next.js 15 and React 19
- **Type Safety**: Full TypeScript support

## 🛠️ Tech Stack

- **Framework**: Next.js 15 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Authentication**: JWT with bcryptjs
- **Icons**: Lucide React

## 🚀 Quick Start

### Prerequisites

- Node.js 18+ 
- npm or yarn

### Installation

1. **Navigate to project folder**
```bash
cd c:\Users\Arteo\front_vision
```

2. **Install dependencies**
```bash
npm install
```

3. **Start development server**
```bash
npm run dev
```

4. **Open in browser**
Navigate to: [http://localhost:3000](http://localhost:3000)

### Available Scripts

- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm start` - Run production build
- `npm run lint` - Run ESLint

## 🔐 Admin Panel

Access the admin panel at `/admin/login`

Default credentials can be configured in the authentication system.
